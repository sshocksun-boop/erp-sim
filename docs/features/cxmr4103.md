# cxmr4103: Sales order queries

Queries all pages of order details by an inclusive order-date range.
See the [README](../../README.md) for transport and shared configuration.

## Usage

Save this JSON request to a UTF-8 file and pass it with `erp-sim --request FILE`:

```json
{
  "command": "cxmr4103",
  "feature_args": {
    "pattern": "S1702*",
    "date_from": "2026-09-10",
    "date_to": "2026-09-11"
  }
}
```

| Feature field | Meaning |
| --- | --- |
| `pattern` | Required order-number pattern |
| `date_from`, `date_to` | Required inclusive YYYY-MM-DD order dates |

## Query behavior

Patterns accept ASCII letters, digits, underscore, hyphen, * and ?, up to
80 characters. Dates must be valid, ordered and within 2000..2099.
Resolve relative dates in Asia/Shanghai before constructing a request.
Example dates are not rolling defaults.

The query always uses order date and includes internal orders. Delivery-date,
customer, status, plant and projection filters are unsupported.
Pagination is automatic; results contain line items.

Common order prefixes: S1701 for 电一分厂/电一SKD散件, S1702 for 电二,
S1704 for 电一无刷洗衣机 and S1705 for 电一无刷. Append * for all matching orders.

## Outputs

```json
{
  "command": "cxmr4103",
  "output": "outputs/orders.json",
  "feature_args": {
    "pattern": "S1701*",
    "date_from": "2026-09-10",
    "date_to": "2026-09-11"
  }
}
```

The output file contains the same full JSON response as stdout. Rows use stable
ERP field IDs and string source values; preserve identifier zeros and precision.

## Result checks

Full success requires exit zero, ok, data.complete, matching returned/expected
row counts and session.logout_verified. A complete zero-row response is valid.
Timeouts, missing data and unverified logout are not empty successes.

Read data.columns for ERP field IDs. Common fields include oea01_1 (order),
oeb03 (line), oea02 (date), oeb04_1 (product), oeb12 (quantity), oeb05 (unit).
order_count can be smaller than row_count.

Request the result contract with:

```json
{"command":"schema","feature_args":{"kind":"response","feature":"cxmr4103"}}
```
