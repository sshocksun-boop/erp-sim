# cxmr4103 order queries

Read this file when forming an order request.
Read [Connection](connection.md) for shared transport and configuration.

```json
{
  "command": "cxmr4103",
  "feature_args": {
    "pattern": "S1702*",
    "date_from": "2026-09-10",
    "date_to": "2026-09-11"
  }
}
```

Dates are examples, not rolling defaults. Resolve relative dates in Asia/Shanghai.
All three fields are required. Dates are inclusive, exactly YYYY-MM-DD, ordered
and within 2000..2099. Pattern accepts ASCII letters, digits, underscore, hyphen,
* and ?, at most 80 characters. * matches any sequence; ? matches one character.

Common prefixes: S1701 for 电一分厂/电一SKD散件, S1702 for 电二, S1704 for
电一无刷洗衣机 and S1705 for 电一无刷. Append * only when appropriate to the request.

Order date and inclusion of internal orders are fixed. Delivery-date, customer,
status, plant, page-limit and projection inputs are unsupported.
Do not fabricate fields. Explain any filtering performed locally on a complete
verified result, retaining the original query scope.

Pagination is automatic. Rows are line items, so order_count can differ from
row_count. Results are a snapshot at query time.

For large results set top-level output and read the saved JSON selectively.
Stdout still contains the full response; do not discard rows through display
limits. Relative paths resolve against caller cwd.
